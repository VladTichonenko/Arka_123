## Сравнение

- Типографика: шрифт существующего сайта; крупные названия и цены,
  второстепенные условия меньшего размера. Текст не обрезается.
- Отступы: три одинаковых колонки на десктопе, один вертикальный ряд на телефоне.
  Крупные скругления, белая вложенная панель, круглые номерные метки и плашки.
- Цвета: чёрный и белый, лайм #e7ff00 в акценте периода «Полдня» и значках CTA.
  Окружающий фон секции сохранён из существующего сайта.
- Изображения: три отдельные генерации built-in image_gen, 1000×1000 WebP,
  18–23 КБ. Кремовые 3D-предметы с аркой на чёрном фоне; все три загружены.
- Содержание: исходные тарифы и условия сохранены. Из референса перенесён стиль,
  а не подписочная модель; бесплатные периоды и скидки не добавлены.

## Проверки

- Все три ценовые плашки после исправления лежат на одной горизонтали.
- При ширине 390 CSS px ширина страницы 390 px, карточки по 354 px:
  горизонтального переполнения нет.
- «Обсудить тариф Полдня» переводит к #contact; верх формы примерно на 78 px
  ниже края viewport, под шапкой.
- Ошибок браузера в проверочной вкладке нет.
- Финальные `npm run lint` и `npm run build` прошли.
- Временное изменение viewport для QA сброшено.
