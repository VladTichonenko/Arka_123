# АРКА 123

Адаптивный сайт пространства для мастер-классов и семинаров в Минске. Проект выполнен на React, TypeScript и Vite по [тестовому заданию](https://docs.google.com/document/d/1hQdub1ngIcIsy4fcKDSN-V59NcwpJjLQV7XLlUCwE8Q/edit?tab=t.0).

## Контекст для Codex

Рабочая копия находится в папке проекта «Тестовое задание арка 123».
Новые чаты получают основные решения из `AGENTS.md`; история и карта файлов
сохранены в [контексте проекта](docs/project-context.md).

## Запуск

```bash
npm install
npm run dev
```

Проверки: `npm run build` и `npm run lint`. Готовую сборку можно открыть через `npm run preview`.

## Что реализовано

- Чёрный фирменный прелоадер до 6 секунд: рисование арки, появление цифр, названия и слогана, переход к светлому сайту. По последнему запросу финальная подсветка удалена. Кнопка позволяет пропустить вступление. При `prefers-reduced-motion` вступление пропускается автоматически.
- Анимация логотипа при наведении и клике в шапке; клик возвращает к началу страницы.
- Первый экран на всю ширину окна по лаймовому референсу: статичная волнообразная лента в фирменной жёлто-лаймовой палитре #e6f17e, текст слева и фото зала с белыми плашками справа. Второй экран — три исходные карточки с лаймовыми акцентами: первая и третья с фотографией на фоне, средняя салатовая. Перед сценой облёта Арины добавлен блок о пространстве с двумя настоящими фотографиями и кнопкой к форме. Затем идут сцена облёта Арины и отдельный блок с её фотографиями, затем рейтинг Google с картой. Прежняя секция «Свет. Масштаб. Свобода.» удалена. Правила образа: `docs/arina.md`.
- Полноширинная сцена с Ариной в комнате: вертикальный скролл управляет видеооблётом камеры на 360°, по бокам меняются три главы описания. Лицо взято из исходного портрета; актуальное видео — Veo 3.1 в 1080p, общий расход OpenRouter $2.944. Reduced motion — статичный кадр и кнопки. Подробности: `docs/arina-orbit.md`.
- Главная страница: о пространстве, сцены с Ариной, пять форматов событий, фотогалерея с просмотром, услуги, тарифы, отзывы и футер. Кнопка «Осмотреть зал на 360°» на фотографии футера открывает панораму зала в модальном окне; отдельная секция тура удалена. Прежние блок персонажа, отзывы и отдельное расположение под прогулкой убраны; по последнему запросу исходный блок из трёх демонстрационных отзывов восстановлен из истории чата после тарифов. Форма включена в футер с фотографией, белым информационным блоком и бегущим слоганом.
- Яркие карточки пяти форматов: наша Арина в нашем зале, единый салатовый фон, крупные заголовки и кнопки к заявке. Карточки немного выше, нумерация убрана. Для каждой генерации использованы исходный портрет и настоящие фото комнаты. Изображения — концептуальные ИИ-сцены, а не съёмка мероприятий. Промпты: `docs/format-arina-image-prompts.md`.
- На компьютере пять карточек форматов пролистываются вертикальным скроллом. На телефоне карточки листаются горизонтально и кнопками.
- Три варианта разовой аренды: карточки со списками сценариев, две светлые и центральная тёмная, на таком же фоне с волновой лентой, как первый экран. Блок подготовки к аренде «Что обсудить перед арендой.» остаётся белым. Цены и условия сохранены.
- Чат Арины подключён к OpenRouter (Qwen3.7 Flash) через серверный /api/chat: знания об объекте, контекст диалога, калькулятор аренды и контакты владельца для подтверждения брони. Белый фон, салатовые кнопки, быстрые вопросы в одну строку. Сообщения обрабатываются OpenRouter; автоматического бронирования нет.
- Мобильная навигация, адаптивные секции, оптимизированные фотографии помещения из материалов задания.
- Все секции на всю ширину окна, без прежних ограничений 1440/1240 px. Общие адаптивные боковые отступы, пропорциональные карточки и фотографии для широких мониторов; отдельная адаптация для невысоких ноутбуков, планшетов и телефонов.

Google Street View панорама у здания перенесена из первой ячейки галереи
в блок с рейтингом #google-rating. Сохраняются разворот на весь экран
и открытие в Google Maps. Перед галереей добавлены четыре преимущества и
концептуальная ИИ-схема зала по настоящим фотографиям (не обмерный план).
Галерея оформлена пятью скруглёнными фотокарточками в ряд на широком экране;
последняя затемнена и показывает «+ 2 фото». Все шесть фотографий зала и здания доступны в
модальном просмотре; первая — room-main.webp. Для панорамы можно задать
собственный VITE_GOOGLE_MAPS_EMBED_API_KEY.
Прежнее исключение видео отменено новым запросом от 22 октября только для сцены облёта Арины; обычный видеоблок не добавлен.

После знакомства с Ариной вместо прежних трёх карточек преимуществ размещён
блок с салатовой карточкой Google 5.0, пятью тёмными звёздами и
панорамой Google Street View у здания на Петра Мстиславца, 10.
По последнему запросу заголовок карточки — «Наша оценка на картах Google»;
прежняя демонстрационная подпись удалена. Значение 5.0 задано статично,
получение актуального рейтинга Google не подключено.

## Данные и форма

Содержание существующих блоков описывает объект и аренду: окна 4 × 3,5 м,
потолки до 4,5 м по материалам задания, архитектуру, варианты использования,
подготовку расстановки и выбор времени. Вместимость и оснащение не выдуманы:
их предлагается уточнить до бронирования. Обзор интерьера подписан как 360°
из одной точки; ИИ-сцены не подтверждают наличие мебели и техники.

Компания и персонаж вымышлены. Цены и отзывы служат демонстрационным наполнением; по последним запросам видимые пояснения к отзывам удалены. Фотографии помещения взяты из папки обработанных материалов задания.

По последнему запросу форма возвращена внутри нового футера: настоящее фото
зала с формой поверх, белый блок с адресом и ссылками, бегущая строка со слоганом.
Нижняя белая часть футера имеет скруглённую форму панели и небольшой статичный
наплыв на фото. Весь футер прокручивается обычно, без закрепления и выдвижения.
По последнему запросу кнопка паузы у строки удалена; при reduced motion она статична.
Форма отправляет подтверждение заявки через EmailJS на e-mail заявителя.
Шаблон в фирменном оформлении: имя, дата начала, количество суток, комментарий
и адрес. Исходник — `emails/booking-confirmation.html`.
Телефон и комментарий раскрываются по желанию; основные поля — имя, e-mail,
дата и количество суток. Календарь занятости не подключён: письмо подтверждает
получение заявки, окончательные условия согласуются отдельно.
Для отправки используется `.env.local` (на этой рабочей копии заполнен):

```dotenv
VITE_EMAILJS_SERVICE_ID=default_service
VITE_EMAILJS_TEMPLATE_ID=template_arka_booking
VITE_EMAILJS_PUBLIC_KEY=your_public_key
```

После изменения переменных перезапустите Vite. Используется только публичный
ключ EmailJS; приватный ключ, пароль Gmail и OAuth-токены в проект не нужны.
При переносе на хостинг задайте эти переменные в его настройках сборки.
Без конфигурации форма сообщает о незавершённой настройке; успех показывается
только после ответа EmailJS. Проверки отправки и валидации: `npm run test:booking`.

## ИИ-консультант Арина

База знаний и калькулятор — `server/knowledge.ts`; API — `server/chat.ts`.
Арина знает площадь, окна, потолки, адрес, форматы, текущие тарифы и пределы
подтверждённой информации. Для подтверждения брони даёт
vlad6867911@gmail.com и +375336867911; не проверяет календарь и не создаёт бронь.
При изменении цен на сайте обновляйте базу знаний и тесты калькулятора.

Ключ хранится **вне проекта**: `~/.config/arka123/server.env` (права 600).
Для другой машины задайте серверные переменные `OPENROUTER_API_KEY` и
`OPENROUTER_MODEL=qwen/qwen3.7-flash`, либо `ARKA_CHAT_ENV_FILE` с путём
к приватному env-файлу. Никогда не используйте префикс `VITE_` для ключа.
Запросы посетителей отправляются через сервер в OpenRouter; полная переписка
на диске приложением не сохраняется. Ограничены история, длина, число
параллельных запросов и частота (20 запросов в минуту на IP).

В разработке API работает вместе с `npm run dev`, в preview — с
`npm run preview`. Для запуска готового приложения с API нужен Node.js 24+:

```bash
npm run build
npm start
```

По умолчанию `http://127.0.0.1:3000`, адрес и порт задаются через `HOST` и `PORT`.
Для публикации нужен Node-сервер: статический хостинг сам по себе не выполнит API.
Проверки серверной части: `npm test`. Ошибки провайдера показывают понятное
сообщение, повтор запроса и контакты, без подмены ответа локальной заглушкой.

Калькулятор: 120 BYN/час, минимум 2 часа; ровно 4 часа — 420 BYN,
ровно 8 — 760 BYN. Для других сроков — почасовой ориентир; комбинации пакетов
не выдумываются. Для 7 часов показывает 840 BYN и предлагает как альтернативу
расширить аренду до 8 часов за 760 BYN. Дробные часы рассчитываются пропорционально
только как предварительная оценка. Даты, оснащение, продление, округление
и итоговые условия подтверждает владелец. Демонстрационный статус тарифов сохранён.
